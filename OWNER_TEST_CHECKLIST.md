# Walk With God Owner Checklist

Use this before sending the app link to testers.

## Before You Send

- Confirm Railway shows the latest deployment as successful.
- Open https://walk-with-god.org in a private/incognito browser window.
- Create a brand-new test account.
- Confirm the account can log out and log back in.
- Confirm the Start Here checklist appears after login.
- Choose a focus from the Focus Library.
- Open one day and confirm the full passage loads.
- Try Read Passage Aloud.
- Save a private note and confirm it appears in the notes library.
- Mark one day complete.
- Open Community and create one check-in.
- Comment or react to a community check-in.
- Open Prayer Requests and submit one test request.
- Open Reminder Settings and save an app notification reminder preference.
- Open each Premium preview section:
  - Premium Preview
  - Breathwork Prayer
  - Faith-Led Yoga
  - Bible Study
  - Walking Sessions
- Send a test feedback message using the Feedback section.
- Check the Admin dashboard to confirm feedback appears.
- Test on both desktop and phone if possible.

## Known Notes For Testers

- Premium is preview-only right now. No payment is active yet.
- Text reminders are intentionally paused while Twilio business compliance is being completed.
- Email reminders are intentionally paused while email setup is being finalized.
- Browser/app notifications are the only reminder channel to test right now and may vary by device.
- Read aloud depends on browser voice support. The app tries to use Google UK English Female when available.

## What You Want Feedback On

- Was account creation easy?
- Was it clear what to do first?
- Did the focus/day layout make sense?
- Did the active time with God idea feel encouraging?
- Did notes, community, and prayer requests feel useful?
- Did anything feel too crowded or confusing?
- What premium sections sound most valuable?
- What would make someone return tomorrow?
