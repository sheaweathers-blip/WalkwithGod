# Walk With God Premium Starter Scripts

These are recording-ready starter scripts for the first premium previews.

Recommended workflow:

1. Record the voiceover first.
2. Add the Walk With God logo intro in Canva.
3. Add peaceful nature or wellness visuals.
4. Add the Scripture and reflection text as simple slides.
5. Export as MP4.
6. Upload as unlisted video for testing.

- `02-faith-led-yoga-begin-in-stillness.txt`
