# Abide Breathwork Prayer Scripts

This folder contains the 30-day Abide Breath Prayer series for Walk With God.

The first seven scripts match the finished Week One breathwork videos already added to the app. Days 8-30 are recording-ready starter scripts that can be used for future Abide videos.

Suggested recording flow:

1. Record the voiceover slowly, leaving room for silence.
2. Add the Walk With God logo intro and ending card.
3. Use calm nature, water, trail, sunrise, sunset, or wellness visuals.
4. Keep music quiet under the voice.
5. Add a short safety note in the description: breathe naturally, stop if uncomfortable, and seek medical advice when needed.
